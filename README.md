# Vermieter OS Desktop

Verwaltung für private Vermieter auf dem Mac und unter Windows: Betriebskostenabrechnung, Mietkonto, Mieterhöhung und
Anlage V. Von OS Factory.

Hier liegen nur die fertigen Programmdateien (unter „Releases“), kein Quellcode. Aus diesen Dateien aktualisiert sich
die Fassung von der Webseite mit einem Klick selbst.

- Mac: macOS 13 oder neuer, Intel und Apple Silicon, signiert und von Apple notarisiert
- Windows: Windows 10 oder 11, 64 Bit
